## 内存观察

同一个临时Node生产服务，256MB堆上限、512MB RSS预算，连续60秒，间隔10秒读取进程RSS。

| 秒 | RSS MB |
|---|---:|
| 0 | 82.1 |
| 10 | 72.7 |
| 20 | 72.8 |
| 30 | 73.1 |
| 40 | 73.5 |
| 50 | 73.4 |
| 60 | 73.6 |

10至60秒增加0.9MB，无持续异常增长，满足本轮固定检查阈值：每次RSS<512MB，10秒至60秒增长<40MB。此结果为短时合成数据负载，不代替线上大数据持续观察。临时测试服务已自动退出；没有打开浏览器、EEOS、启动采集或改动当前本地业务库。现有5173服务未重启，继续运行其原已构建版本；本轮源码变化需更新构建后才反映到该页面。
